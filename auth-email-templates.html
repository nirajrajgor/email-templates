Authentication email questions

What is an account verification email?

An account verification email asks a new user to confirm they own the address they signed up with. It carries a one-time link or code that expires, so nobody can create an account with someone else's email.

How long should a password reset link stay valid?

Keep it short and single use. Many products expire the link within an hour, and it should stop working as soon as the password is changed.

Are there templates for Supabase or Better Auth?

Yes. The Supabase collection and the Better Auth collection are built for those providers and keep their template variables intact.

Do these templates work with Resend, SendGrid, or Postmark?

Yes. Each template is plain HTML with inline CSS, so any email provider that accepts HTML can send it. Replace the sample names and links with your own variables.
